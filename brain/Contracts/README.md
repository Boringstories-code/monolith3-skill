# Contracts

Signed agreements, statements of work, and the terms you actually operate under.

Keep the executed PDF plus a short markdown note next to it: who, what, how much, when it
ends, and anything unusual you'd otherwise forget. The note is what gets read; the PDF is
the evidence.

No payment details or account numbers in here — those are credentials, see
`00-OS/creds/CREDENTIALS.md`.
