# Drawers

Topic packs — groups of skills that only matter when you're doing that kind of work.

A drawer is one markdown file: a table of `Skill | What it does | When it fires`. The agent
reads the drawer first, then the one member skill it needs.

Drawers stay *out* of the always-on menu on purpose, so sessions start cheap.
Nothing lives here in a fresh vault, and twelve skills is too few to need one. This folder is for later.

Name them `drawer-<group>.md` — how you'd say the topic out loud.
