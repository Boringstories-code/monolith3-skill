# Diagrams

Visual thinking. One folder per diagram, with matching basenames:

    my-system/
      my-system.png     <- the rendered image
      my-system.md      <- what it shows, in words

Always ship the markdown alongside the picture. An image alone is invisible to search and
to the agent — the markdown is how the diagram stays findable.
