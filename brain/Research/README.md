# Research

Deep dives you commissioned or ran: market research, comparisons, vendor evaluations,
investigations.

One folder per question. Keep the sources with the conclusion — a research note whose
sources have evaporated is an opinion.

Findings worth keeping get ingested into the wiki so they answer questions later, instead of
sitting here waiting to be remembered.
