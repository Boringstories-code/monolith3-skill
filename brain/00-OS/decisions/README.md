# Decisions

One file per decision worth remembering the reasoning for. Named
`YYYY-MM-DD-<topic>.md` — decisions are the one place a date in the filename is right,
because the date is part of the identity.

Write one when:

- You chose between real alternatives and the losing option was defensible.
- You'll be tempted to revisit it in six months.
- Someone else will ask "why is it like this?"

Don't write one for things with an obvious answer.

Use `_TEMPLATE.md`. The section that earns the file is **"How we'll know if this was wrong"** —
a decision record without a falsifier is a diary entry.

Some files in here are logs rather than decisions — the setup record written the day the vault
was created is the obvious one. Nothing was weighed, so there are no options to list. Write
those as plain prose and skip the template. Padding out fake alternatives to fit a shape is
worse than not using the shape.
