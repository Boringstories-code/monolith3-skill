# Raw: People

Drop zone. Put source material here in whatever shape it arrived — transcripts, article
exports, PDF text, chat logs, highlight dumps, your own long voice-note transcriptions.

Then run `/second-brain-ingest 00-OS/raw/people/<file>` (or point it at this whole folder).

Rules:

- Ingest **reads** this folder and never edits it. Raw stays raw.
- No cleanup needed before ingesting. Messy input is fine; that's the job.
- Filenames should say what the thing is. No dates in the name.
- Nothing sensitive: no credentials, no private notes about people.

Ingested material becomes pages in `00-OS/wiki/people/`. Hub: [[00-OS/wiki/people/_index|People]]
