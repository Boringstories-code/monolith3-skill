# Learnings

One file per recurring job or skill, recording how it actually goes in practice.

```markdown
## What works
## What missed
## Standing guidance
```

The pattern: before a recurring job runs, read its file. After it runs, append what happened.
Over a few months this is the difference between a skill that's theoretically right and one
that's right for you.

Keep it short. A learnings file nobody reads because it's forty entries long has stopped
working. Prune to what still applies.
