# Brainstorms

Thinking out loud, before it's a plan. Messy on purpose.

One file per session of thinking. Date in the frontmatter, not the filename. When a
brainstorm turns into something real, it graduates to `Projects/` or `Apps/` and this file
stays as the record of how you got there.
