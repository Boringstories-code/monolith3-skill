# Apps you built

One folder per app, tool, or product you've built. Code usually lives elsewhere (a real repo);
this is the *thinking* around it — the spec, the decisions, the notes, the next line.

If a project has a code repo, record its path in `Projects/REGISTRY.json` so the agent can
find it without being told every time.
