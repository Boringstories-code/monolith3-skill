# Books

One note per book. What it said, what you actually took from it, and the lines worth keeping.

The useful pattern is not a summary — it's *what changed because you read it*. A book note
with no behaviour change in it is a receipt, not a note.

Raw highlight exports go to `00-OS/raw/learning/` and get ingested; this folder is for the
per-book note you write yourself.
