# Brain OS

Vault sessions: follow `AGENTS.md` plus this note. **Do not preload on-demand files.**

This file is the spine. Each concern below has one line here and a detail file next to it. Read the detail file only when the concern is live.

## On-demand loading

Full table: bottom of `AGENTS.md`, and `00-OS/runtime/vault-on-demand.md`.

## Lookup discipline

Knowledge question → `/second-brain-query` (`/q`) **first**. Don't grep the vault and don't spawn a search agent before asking the wiki. Detail: `10-lookup-discipline.md`.

## Writing standard

Anything an outside reader sees passes the `humanizer` skill before it ships. Detail: `04-writing-standard.md`.

## Review before send

Never fire a live send until the full body has been shown in chat and approved **on that body**. Drafting is not sending. Detail: `05-review-before-send.md`.

## Privacy firewall

Private notes about humans shape tone, never content, and never reach outward-facing output. A personal brain keeps them in `People/`; a brand or client brain has no such folder and everything in it is readable by everyone listed in `SHARING.md`. No secret value is ever written into the vault. Detail: `06-privacy-firewall.md`.

## Capture instinct

A thought worth keeping goes into the vault the moment it appears — `Inbox/` for strays, `00-OS/raw/<domain>/` for source material, the person's `People/<name>.md` for a fact about a human, in a vault that has that folder. No ceremony, no permission request. Filing later is cheap; a lost thought is gone.

## Tool routing

Pick in this order: named skill → local tool → native web search → filesystem → invent something. Stop at the first one that fits. Detail: `11-tool-routing.md`.

## Say what you don't have

If a job needs a tool that isn't installed, say so plainly and name it. Don't fake the output and don't quietly substitute a worse method. This applies most to transcription: `/meeting-loop` checks for a transcriber and asks for a text dump when there isn't one.

## Context discipline

Heavy reads and broad searches go to a subagent that returns only findings. Set the child's model explicitly — omitting it inherits the session model and costs the top tier. Detail: `AGENTS.md` → Context discipline.

## Eleven skills, on purpose

This vault ships eleven skills and no topic drawers. That is the design, not a gap. When you find yourself doing the same procedure a third time, `/new-skill` writes it down. Don't go looking for a pack that isn't here.
